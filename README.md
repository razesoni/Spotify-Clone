# Music Player UI — Learning Project

A frontend music-player exercise using HTML, CSS and JavaScript. This is an educational interface project, not an official Spotify product.

## Run locally

From the repository root:

```bash
python -m http.server 8080
```

Open http://localhost:8080. No application backend is included. Third-party images, music and other assets retain their respective rights.
